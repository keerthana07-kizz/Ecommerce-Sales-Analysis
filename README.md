# 📊 E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data using Python and
provides insights into sales performance, products, categories,
cities, customers, payment methods, and monthly sales trends.

The goal is to understand sales patterns and identify important
business insights from the dataset.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- GitHub
- VS Code

---

## 📂 Dataset

The dataset contains 25 e-commerce orders with the following
information:

- Order ID
- Order Date
- Customer Name
- Product
- Category
- City
- Quantity
- Unit Price
- Payment Method

---

## 🔍 Analysis Performed

The project includes:

1. Data loading
2. Dataset structure analysis
3. Missing value analysis
4. Statistical analysis
5. Total revenue calculation
6. Sales by product
7. Sales by category
8. Sales by city
9. Monthly sales analysis
10. Sales by payment method
11. Customer sales analysis
12. Quantity sold by product
13. Average order value
14. Top products
15. Top cities
16. Highest revenue order
17. Sales visualizations

---

## 📈 Key Results

- Total Revenue: ₹334,800
- Total Orders: 25
- Highest revenue product: Laptop
- Highest revenue city: Hyderabad
- Highest sales category: Electronics
- Highest sales payment method: UPI
